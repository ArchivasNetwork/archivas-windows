# Archivas Windows Farmer & Node App

The official Windows desktop application for farming and running a node on the **Archivas Proof of Space and Time (PoST)** blockchain.  
This app provides a simple, reliable and fully automated way for anyone to join the network without touching the command line.

## 🚀 Features

### **One-Click Node + Farmer**
- Start a full Archivas node instantly  
- Auto-discovers peers and syncs to the latest chain  
- Runs the farmer in the background and submits proofs automatically  

### **Full PoST Support**
- Scans existing plots  
- Displays proof checks  
- Shows challenge responses in real time  
- Supports k28+ plotting formats  

### **Real-Time Syncing**
- Shows current block height  
- Displays sync progress  
- Monitors timelord updates  
- Automatically reconnects if the network drops  

### **Zero Configuration Required**
- No manual settings  
- No CLI commands  
- No environment variables  
- Install → Run → Farm  

### **Optimized for Windows**
- Built for stability on Windows 10 and Windows 11  
- Lightweight CPU usage  
- Designed for long uptime

## 📚 Getting Started

### **1. Install the App**
Download the `.exe` from Releases and install normally.

### **2. Open Archivas**
On launch, the app will:
- Connect to the Archivas Devnet  
- Start node syncing  
- Activate the farmer once synced  

### **3. Add Your Plots**
The app automatically scans your system for compatible plots.  
You can also manually add directories in **Settings → Plot Folders**.

### **4. Keep the App Running**
The longer you stay online, the more your node contributes to:
- Network security  
- Chain finality  
- Consensus stability
